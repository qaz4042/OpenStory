# 常用界面汉化补齐

日期：2026-11-23。按用户要求收在常用程度，不继续逐图、逐任务展开。

本轮范围：

- 主菜单 12 个按钮与标题；保留按钮原有交互状态和左侧图标。
- 角色装备窗口标题、装备栏位；保留原框、人物轮廓及装备图标。
- 世界地图标题、导航／飞行／搜索按钮、搜索说明。
- 状态栏和属性窗口的职业显示；仅在显示处翻译，职业判定不使用译名。
- 装备说明的类型、攻击速度、强化次数、属性、需求和职业限制；中英切换刷新同一装备说明。
- HP／MP、箭矢／子弹／飞镖不足、冷却和卷轴结果等客户端提示。
- 常见地图、区域名称的文本覆盖及编号后缀；未知名称回退原文。当前为独立地图词库，后续若继续扩展应迁入按类别＋ID 的数据覆盖表。

未纳入：世界地图插画内的英文地名、完整任务／NPC 对话、低频窗口、服务端公告、底栏大图标与键位动作贴图内的全部英文。搜索结果是否真正可查询、按钮是否有对应玩法，仍取决于已有功能；本轮不新增这些玩法。

代码与词库：`src/Localization/Messages.h`、`Vocabulary.h`、`MapNames.h`。译文按项目自译记录，未宣称来自经核实的国服原包；台账见 `terms.csv`。

验证：`python3 tests/localization-settings.py` 使用本机 NX 和生产对象，隔离设置、无需连接服务端；覆盖中英文、装备／地图／菜单／装备说明截图、回退行为、语言切换、既有提示回调及窗口／全屏回归。截图在 `build-macos/localization-check/coverage-*`。实际游戏仍由用户手动重启后复测。
